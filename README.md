# ItemGPT Website Decision Intelligence

An advanced ItemGPT demonstration that turns public website evidence into a prioritized growth decision, implementation-ready page strategy, and downloadable decision packet.

## Live AI agent

- **Agent:** Website Decision Intelligence Agent
- **Agent ID:** `dynamic-agent-Vd8b9fHBljnv`
- **Runtime:** ItemGPT at [atlas.item.com](https://atlas.item.com)
- **Tools:** ItemGPT Browser Automation MCP

## Demonstrated workflow

1. Frame the business objective.
2. Inspect target and competitor websites.
3. Capture public evidence from pages, sitemap and robots directives.
4. Compare positioning, conversion paths, SEO and trust.
5. Rank opportunities using a five-factor score.
6. Produce a complete page strategy and draft copy.
7. Return an implementation backlog with acceptance criteria.
8. Export a portable Markdown decision packet.


The repository is ready for a Vercel import with no required environment variables.

## Evidence policy

The demonstration includes two category-correct sample analyses: UNIS versus integrated 3PL competitor NFI, and Cubework versus flexible-warehouse competitor ReadySpaces. It does not invent private analytics, rankings, conversion data, Lighthouse scores or screenshots. Browser screenshots are included only when ItemGPT returns a real artifact URL.
